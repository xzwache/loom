# loom

A coding-agent harness written in Go. The core mirrors learn-claude-code sessions s01–s10;
`references/loom-features.md` lists the features planned on top of it.

- Follow `docs/STANDARDS.md` for all code, tests and git work.
- Run `make check` before declaring work done.
- Git: commits, branches and PRs carry no AI/tool attribution: no `Co-Authored-By` trailer,
  no "Generated with" line, and no AI names in branch names.
